# Посмотри в окно

Учебный проект Яндекс Практикума: стилизация готового приложения «Посмотри в окно» по макету.

## Описание

Приложение показывает видео из разных городов. Слева — основной плеер и форма поиска (город и время суток), справа — заголовок и список карточек с видео. При клике на карточку видео в плеере меняется, кнопка «Показать еще» подгружает дополнительные карточки. Пока данные загружаются, показываются прелоадеры, а если видео не найдено или произошла ошибка — блок с сообщением.

## Что сделано

Разметка и скрипт были получены в заготовке. В рамках проекта написан файл `styles/style.css`:

- лейаут на flex: центрирование страницы, раскладка блоков, форма поиска, карточки;
- размеры и отступы по макету, `object-fit` для видео и миниатюр;
- оформление текстов: заголовок, названия карточек с многоточием, описание с `line-clamp`;
- кастомные чекбоксы на псевдоэлементах, класс `.visually-hidden` для скрытия нативных элементов;
- состояния `:hover`, `:active`, `:focus-visible` для кнопок, карточек и элементов формы;
- `cursor: pointer` для кликабельных элементов, `position: relative` для контейнеров прелоадеров.

## Стек

HTML, CSS, JavaScript.

## Как запустить

Откройте файл `index.html` в браузере. Для загрузки видео нужен доступ в интернет.
